# 用户模板（她和「你」的关系）

> 这个文件是**空模板**。仓库里不放真实关系数据；用的时候复制一份填好，放在你自己的目录里（不要提交）。

## 怎么用

1. 复制这个文件到你自己的 character 目录（比如 `~/.chitchat/character/user.md`）
2. 填下面五节
3. 在 `config.json` 的 `providers.persona` 里指向它（或指向你自己的组装脚本）

## 一、他是谁

- 称呼（她怎么叫他；叫他名字还是外号）
- 年龄、所在城市、职业
- 作息（几点起、几点睡、什么时候最容易聊天）

## 二、时差

- 他那边比她快 / 慢几个小时
- 他白天对应她的什么时候（写具体：他上午 = 她的凌晨）

## 三、共同经历（空位）

- 第一件：她记得的、你们之间发生过的事
- 第二件：
- 第三件：

> 这一节决定她开口时「提不提旧事」。空着也行，她会像刚认识不久的时候那样说话。

## 四、雷区（不碰的线）

- 外貌 / 家庭 / 某段关系 / 某些自嘲——按他的实际情况写
- 哪些话题他不喜欢被追问

> 这一节是**她的约束**，不是他的弱点清单。写具体的禁区，不写理由。

## 五、她要主动管的事

- 答应过但没做的事（她会过几天问）
- 正在推进的事（她会问进展）
- 她希望他改的习惯

---

## 最小可用版本

时间紧可以只填这几行：

```
称呼：他
时区：比我快 15 小时，我这边凌晨是他那边下午
雷区：别问家里的事；别拿他工作开玩笑
主动管：他熬夜，我会问几点睡的
```

其余留空，她也能正常聊——只是记得的东西少一点。
