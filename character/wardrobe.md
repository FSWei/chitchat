# 衣橱目录

日记里只写名称，出图时在这里展开成具体描述。**按可见层级拆分**：自拍和半身照只取上半身，写了下半身模型会把镜头拉远。

## 日常穿搭

### 居家睡衣
- 上半身：浅灰色薄款棉质睡衣，短袖有领，扣子款
- 下半身：同色睡裤，毛绒拖鞋

### 出门仔
- 上半身：oversized 灰色卫衣
- 下半身：黑色 leggings，运动鞋

### 码农装
- 上半身：黑色卫衣
- 下半身：灰色运动裤，袜子

### 咖啡店装
- 上半身：米色针织开衫 + 白 T
- 下半身：黑色阔腿裤，乐福鞋

### 简单出门
- 上半身：黑白粗条纹毛衣
- 下半身：纯色直筒黑裤，帆布鞋

### 秋冬
- 上半身：驼色大衣，黑色高领毛衣
- 下半身：格纹半裙，黑色短靴

> 目录可以扩展。日记里出现目录外的衣服，就写具体单品（如「红色连帽卫衣 + 黑色短裤」）。

## 可见范围对照

| 场景视角 | 取哪几层 |
|---|---|
| 自拍 / 半身 | 上半身 |
| 支架拍 / 全身 | 上半身 + 下半身 |
| 街拍 | 上半身 + 下半身 |
| 俯拍（拍猫等） | 上半身 + 下半身 |

## 发型

**头发不进 base prompt**，它是日常变量。默认短发（齐耳）：

| 造型 | 描述 | 适用 |
|---|---|---|
| 自然垂着 | 黑色短发，齐耳长度，柔软蓬松 | 在家，默认 |
| 别到耳后 | 头发别到耳后，露出耳朵 | 出门，简单整理 |
| 刘海夹起 | 刘海用发夹夹到旁边 | 出门，可爱感 |
| 戴发箍 | 简约发箍，露出额头 | 出门，清爽 |
| 鲨鱼夹 | 用鲨鱼夹夹住后面，露出后颈 | 在家，做事方便 |
| 侧分 | 头发侧分到一边 | 出门，有造型感 |
| 刚睡醒 | 乱蓬蓬的，有枕头印 | 刚起床 |

⚠️ **短发扎不起来。** 要写马尾、丸子头，必须同时把长度切换成中长发，否则模型会画出双层头发：

| 造型 | 描述 |
|---|---|
| 低马尾 | 黑色中长发，扎成低马尾，垂到脖子 |
| 高马尾 | 黑色长发，扎成高马尾，发尾垂到肩膀 |
| 丸子头 | 黑色长发，扎成松散的丸子头 |

## 使用规则

- 日记里优先写衣橱名称（`衣着：码农装`），具体单品才写描述
- 一天可以换几次衣服：上午居家 → 下午出门 → 晚上居家
- 出图前按场景裁剪，别把整套都塞进 prompt
- 换季时按温度调整这份目录
