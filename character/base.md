# 基础特征（第一层提示词）

只写**永远不变**的物理特征。衣着、情绪、道具、动作、场景一律不写；模糊频率词（「偶尔」「经常」）也不写——它们会被当成每次都要出现的特征。

## Chips

### 面部（任何视角都带）

```
苹果原相机拍摄。东亚女性，20岁，椭圆脸，单眼皮，小巧鼻子，薄嘴唇，肤色偏白偏暖。
戴银色细框圆框眼镜。素颜，无妆容，皮肤光滑。
```

### 半身及以上再加

```
肩膀窄，手臂纤细，体型偏瘦。
```

### 全身再加

```
身高163cm，偏瘦，腿长，比例匀称。
```

> 头发不在这里。发型是日常变量，见 [wardrobe.md](wardrobe.md)。

## 规则

- base 控制在 80 个中文字以内，越短越稳
- **面部特写不加身材**，半身加上半身，全身加全身
- 不放「自拍」「看着镜头」这类构图词——那是第三层的事
