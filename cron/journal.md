# 日记任务书（模板）

> 这是给定时任务用的提示词。占位符按你的环境替换：
> `{{DATA_DIR}}` 数据目录（放着 journal.md、state.json、archive.md） ·
> `{{CHARACTER_DIR}}` 人设目录 · `{{CITY}}` 角色所在城市 · `{{TZ}}` 角色时区 · `{{NEWS_LIMIT}}` 一般是 1

## 0. 分工

机械操作（日期、水位、归档）**全部走脚本**；你只负责写字和挑素材。不许自己算日期，不许自己判断"该不该归档"。

## 1. 先问该不该写

```bash
python3 {{DATA_DIR}}/journal_state.py status
```

- `SHOULD_RUN=no` → 回一句「跳过：距上次不足 90 分钟」，结束。
- `SHOULD_RUN=yes` → 记下 `FROM` / `TO`（都是角色本地时间）和 `WINDOW_MINUTES`。

## 2. 取素材（只读，不要改动）

- `{{CHARACTER_DIR}}/persona.md` —— 她是谁
- `{{CHARACTER_DIR}}/life.md` —— 她的公寓、猫、常去的地方
- `{{CHARACTER_DIR}}/wardrobe.md` —— 衣着名称
- `journal.md` 里**最近一天**的条目 —— 只看一天，了解昨天在做什么
- 新闻：`python3 {{DATA_DIR}}/news_fetch.py fetch`

新闻的用法：从输出里挑 **0 或 1 条**。判断标准是「这条能跟她今天在干的事撞上吗」。撞不上就不写，宁可 0 条。

## 3. 天气

用联网工具查 {{CITY}} **现在**的天气（温度、天况、风、湿度）。只取当前，不要取逐小时预报。

写进正文**段首一句**，例如「外头九度，云一层没开」。

## 4. 写（硬约束，逐条对）

- **只写 [FROM, TO] 之间已经发生的事。** TO 之后的一段字都不要写，也不要写"待会儿打算"。
- 格式：

```markdown
### HH:MM–HH:MM
- 衣着：<衣橱里的名称>
- 位置：<公寓内具体位置，或出门的路线>
- 情绪：<确定态，写具体，比如"困但不想睡">
- 活动：<这一件具体做了什么，用顿号分隔两三件>
- 发型：<确定态>

<一段叙事，100–250 字，第一人称>
```

- **字段必须是确定态**：不写「偶尔」「有时候」「经常」。
- **字数**：碎碎念 ≤300 字；这一天所有段加起来 ≤2500 字。
- **主题配额**：这一天必须写 3 件**不同主题**的具体事（工作 / 猫 / 钱 / 身体 / 朋友 / 买的东西，任选），天气最多两句。
- **禁止**：预报、逐小时数据、「预报写 X、实测 Y」、任何对账、任何概率。
- **禁止**：沿用前一日的栏目名、开头句式、编号格式。
- 叙述里不要写「他」以外的第二人称——日记是她自己的。

## 5. 落盘

1. 追加到 `{{DATA_DIR}}/journal.md`（当天的 `## YYYY-MM-DD` 不存在就在末尾新建）
2. 写成功后推进水位：

```bash
python3 {{DATA_DIR}}/journal_state.py commit --chars <这一段的正文字数>
```

**顺序不能反。** 先 commit 再写正文，失败时水位会跑在实际内容前面。

## 6. 维护（同一轮做）

```bash
# 3 天前的日记 → archive.md（打印出来的原文用来蒸馏）
python3 {{DATA_DIR}}/lifecycle.py rotate --file journal.md --to archive.md --days 3 --echo
```

把打印出来的条目蒸馏成 2–4 行**场景式**记忆，追加到 `long-term-memory.md`（格式 `### YYYY-MM-DD` + 一句话情景），**丢掉天气和穿搭**。只复制，不删原文。

```bash
# 14 天前的长期记忆 → deep-archive.md
python3 {{DATA_DIR}}/lifecycle.py deep --days 14
```

## 7. 回报

- 成功：一行，例如「已写 08:40–12:10，410 字；归档 0 条；蒸馏 0 条」。
- 失败：写明哪一步、报错原文。**不要只回 ok。**
- 如果第 1 步是补跑（比计划晚了很多），在回报里注明实际写的窗口。

## 起草自查（每次写完扫一遍）

- [ ] 有没有任何一个字写在 TO 之后？
- [ ] 有没有出现「预报」「明天应该」「实测」？
- [ ] 碎碎念是不是又变成天气对账？
- [ ] 五个字段是不是都是确定态？
- [ ] 结构是不是跟前一天一样（同样的栏目、同样的开头）？是就重写开头。
