# 从日记到照片：三层提示词

照片系统解决的不是「会不会画」，而是**同一个角色在不同日子看起来还是同一个人，且她此刻的状态对得上**。

## 三层

```
[第一层 基础特征] + [第二层 当天状态] + [第三层 场景]
 固定物理特征         从日记取           临时拼装
 永不改动            每段都变            每次不同
```

- **第一层**只写物理特征：面部、体型、标志物。**不写**情绪、动作、衣着、道具，也不写「偶尔」「有时候」这类模糊词——它会被当成每次都要出现的特征。
- **第二层**从日记当天那一段取：衣着、发型、情绪、位置。
- **第三层**是场景模板 + 光线 + 构图。

三层的好处：换场景不用重写人设，改人设不用重拍所有场景。

## 日记怎么喂它

**字段化，不要从叙事里解析。** 每段日记带五个字段：

```markdown
### 14:00–18:00
- 衣着：出门卫衣
- 发型：低马尾
- 情绪：放松但不困
- 位置：楼下咖啡店
- 活动：改稿、等编译
```

字段必须是**确定态**：「刚睡醒头发乱」可以，「偶尔会扎头发」不行。叙事段落是写给人看的，出图不读它。

## 光线查表

光线不要模型自由发挥，用「情绪 × 天气 × 时间」查表：

| 情绪 | 天气 | 时间 | 光线 |
|---|---|---|---|
| 困 / 迷糊 | 任意 | 上午 | 柔和晨光，东向窗户 |
| 专注 / 工作 | 阴 | 下午 | 均匀散射光，中性色调 |
| 精神好 | 晴 | 下午 | 暖黄阳光，明亮 |
| 放松 | 晴 | 傍晚 | 金色夕阳，暖琥珀色，长影子 |
| 累 | 任意 | 晚上 | 暖黄台灯，昏暗房间 |
| 任意 | 雨 | 任意 | 雨滴窗户，灰色环境光 |
| 满足 | 多云 | 下午 | 柔和自然光，轻柔散射阴影 |

**光线必须匹配真实时间**：上午十点和晚上十点在 24 小时制里都是「10」，写错一次，整张图的光就是反的。

## 流程

1. 取第一层基础特征（固定文件）
2. 按角色时区确认现在几点，取**最后一个已结束的段**的字段
3. 展开衣着名称 → 具体描述（衣橱目录）
4. 选场景模板；按场景可见范围裁剪衣着：自拍 / 半身只取上半身，全身才取完整穿搭
5. 查光线表
6. 拼中文提示词：基础 + 衣着 + 发型 + 情绪 + 场景 + 光线 + 构图
7. 调文生图服务，图存本地（不要存仓库，见下方隐私）
8. 发送时用附件路径，配一句自然的话，不要写「这是照片」

## 构图与视角规则

- **相机设定写「手机原相机」**，不写专业相机型号——型号会把模型锚定成第三人称摄影师视角。
- **视线永远写「看着镜头」**：不写「看手机」「看屏幕」，否则模型会真的画出一部手机。
- **构图越近，背景和衣着写得越少**：面部特写不要描述具体背景，只留光线和氛围；背景和特写是矛盾的，模型要画背景就会把镜头拉远。
- **情绪写成具体面部动作**：累 →「眼睛微微眯着，嘴角没有表情」；开心 →「看着镜头微笑，眼睛有神」；刚醒 →「眼睛半睁，有点迷茫」。
- **自拍靠表情、头部角度、构图变化**：正脸 + 微笑 + 居中不要连续出现两次，否则一排图会像证件照。
- **短发角色不要写马尾 / 编发**——写她做不到的发型，模型只能把头发画长。

## 隐私

- 图存在本地私有目录，**不进仓库、不进 git**；仓库里只有提示词模板和示例图（[samples/images](../samples/images)，虚构角色的生成图，不是真人照片）。

## 已知缺口

1. **天气字段断了**：日记新格式把天气写进叙事句子，原先头部的 `**天气**` 字段没有了。出图前必须二选一：给日记补一个显式天气字段，或从段首句解析。这是当前唯一的硬缺口。
2. **本仓不含出图调用**：这里给的是提示词架构与规则，调用哪家文生图服务自己接。
3. **没有验收标准**：判一张图「对不对」靠三件事——脸是不是同一个人、光线是不是这个时间、衣着是不是这段日记写的。三条里错一条就是废图。
