# 她的日子：分段日记

日记不是日志。日志写「发生了什么」，日记写「她怎么过的」。这两件事的机制完全不同。

## 为什么不是「每天生成一次」

如果每天只在固定时点生成一整天的日记，会有两个逃不掉的后果：

1. **生成的时候，这一天大部分还没发生** —— 只能写预报。第二天有了真实数据，就要对账；一有对账，日记就长出「预报 vs 实测」的二元结构，并且会自我增殖。
2. **漏一次触发就永久丢一整天** —— 机器关着、网络断了、模型挂了，那天在日记里就是空白。

实测过的漂移：连续生成 21 天，单篇从 300 字长到 1600 字，碎碎念九成在写天气；某一天 5800 字里 59% 是天气对账。这不是模型跑偏，是任务书的结构决定的 —— **它每天只能靠预报活着**。

## 模型：双时钟

| 时钟 | 跟随什么 | 用途 |
|---|---|---|
| 日历 | 角色所在时区的墙钟 | 「她那边现在几点」不能错位 |
| 叙事 | 活动段 `[covered_until, now]` | 只写已经过完的那一段 |

两个时钟分开之后，日记里出现的每一段都是**已发生**的：可以直接讲，不需要加「打算 / 准备」。

状态文件 `state.json`：

```json
{
  "date": "2026-11-24",
  "covered_until": "2026-11-24T16:50:10-08:00",
  "finalized": false,
  "segments": [{"from": "...", "to": "...", "chars": 413, "at": "..."}]
}
```

`covered_until` 就是水位：下一次只写它到「现在」的这一段，写完 `commit` 推进。

## 机械部分交给脚本

```bash
python3 life/journal_state.py status              # 该不该写、从哪写到哪
python3 life/journal_state.py commit --chars 330  # 写成功后推进水位
python3 life/journal_state.py finalize --date 2026-11-24
python3 life/journal_state.py reset               # 重开某天（慎用）
```

规则都在脚本里，不靠模型记：

- **最小间隔 90 分钟**：间隔不够就 `SHOULD_RUN=no`，避免一天碎成几十段。
- **跨日滚动**：日期变了，水位重置到当天 00:00，前一晚的空档不补写。
- **首次启用**：当天不补写，从明天 00:00 起算。
- **幂等**：`commit` 只接受「比水位更晚」的时间，倒退直接报错退出。

## 格式

一天一个二级标题，一段一个三级标题，段首一行天气，然后五个结构化字段 + 叙事 + 碎碎念：

```markdown
## 2026-11-24

### 00:00–12:00
- 衣着：居家睡衣
- 位置：书桌→厨房
- 情绪：困但不想睡
- 活动：改报价页布局、煮了一包拉面
外头一直在下那种听不见的雨，玻璃上只有一层水汽……
### 碎碎念
两点的时候人开始飘，代码是对的，脑子不行了。
```

字段是给照片系统用的（见 [IMAGE.md](IMAGE.md)），叙事是给人看的。**字段不能写「偶尔」「有时候」**——出图时没法用。

## 防漂移四条

写任务书时必须同时带上，缺一条就会漂：

1. **字数硬顶**：碎碎念 ≤300 字，全天正文 ≤2500 字。不设上限时，模型每天比前一天长一点。
2. **主题配额**：必须写 3 件不同主题的具体事；天气最多两句。
3. **禁结构复用**：不许沿用前一天的栏目名、打分格式、编号句式，不许连续两天同一句式开头。
4. **连续性只给摘要**：读一份 ≤20 行的 `continuity.md`（未完成的事 + 关系状态 + 连载梗），不要读前一天全文 —— 读全文等于把上一天的模板连同毛病一起复制。

## 关机与补跑

她的一天跟着机器走：机器关着的那段不存在，但也不是失忆 —— 水位停在关机前，开机后补写的是「从水位到现在」这一段，中间的空档不补算。

定时任务如果错过了触发时间，宿主通常会补跑一次（可能是几小时后）。补跑写出来的那一段会覆盖更长的窗口，所以在任务书里要允许「一段写几个小时」，不要假设每段都是一两小时。

## 坑

- **日期按角色的时区算**，不是按你的。用 `TZ=... date` 或脚本里的时区，别用系统本地时间。
- **不要在正文里做天气预报**：想写「明天应该会晴」，改成「明天想出门」。
- **不要用 HTML 注释藏状态**：渲染后看不见，人改日记时也看不见；用 bullet，肉眼可读。
- **cron 会话读不到 skill 文件**：读文件用宿主允许的方式，机械逻辑写成 `.py` 落盘再执行，别用 `python3 -c` 长脚本。
